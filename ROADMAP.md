# Roadmap

## MVP Atual

- Skill descriptor.
- Protocolo operacional.
- Init global.
- CLI stdlib com discovery, assess, plan, check, validate e report.
- Adapters para Codex, Claude Code, Copilot, OpenCode/Qwen e genérico.
- Prompts de papéis especializados.
- Testes básicos.

## Próximos Passos

1. Detectar comandos reais em scripts de manifest, não apenas comandos padrão.
2. Criar validação de imports por linguagem.
3. Adicionar diff budget por batch.
4. Gerar planos de worktree paralelos.
5. Criar templates por stack: Node, Python, Java, .NET, Go, PHP, Ruby.
6. Adicionar scoring de smells mais robusto.
7. Exportar relatório em Markdown + JSON.
8. Criar modo `doctor` para verificar instalação global.
